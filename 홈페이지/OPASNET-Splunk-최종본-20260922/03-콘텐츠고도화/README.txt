OPASNET Splunk · Confluent 노트북용 페이지
==========================================

실행 방법
1. ZIP 파일의 압축을 풉니다.
2. 압축 해제된 폴더 안의 index.html을 더블클릭합니다.
3. Chrome, Edge, Safari 등 웹 브라우저에서 페이지를 확인합니다.

주의 사항
- 서버나 PHP 설치는 필요하지 않습니다.
- index.html만 따로 이동하면 이미지와 디자인이 표시되지 않습니다.
- css 및 images 폴더를 index.html과 함께 보관하세요.
- 외부 공식 자료와 문의 버튼은 인터넷에 연결된 경우에만 열립니다.

구성 파일
- index.html: 노트북에서 바로 실행하는 페이지
- css/solution-splunk-confluent.css: 페이지 디자인 및 반응형 스타일
- images/sub/splunk-confluent/: Confluent 아키텍처 및 로고 이미지

페이지 구성
- 기존 오파스넷 사업소개 상단 배경과 솔루션 메뉴 구조를 반영했습니다.
- 솔루션 메뉴의 "데이터분석" 다음에 "데이터사업"이 표시됩니다.
- 데이터사업의 기본 선택은 Confluent입니다.
- Confluent/Splunk 탭을 누르면 같은 페이지에서 제품 내용이 전환됩니다.

2026-09-18 Splunk 내용 보강
- 제품 소개, 도입 이유, 비교 시 강점, 제품별 구성 및 공식 출처 추가
- 기본 Confluent 탭은 유지하며 index.html#splunk-section으로 Splunk 바로 열기 지원
- 비교 내용은 특정 경쟁 제품의 기능 부재나 성능 우위를 단정하지 않습니다.

콘텐츠 고도화 버전
- 업무별 시나리오, 제품 선택 기준, 도입 단계 및 PoC 검증 지표 추가
- 시나리오는 공식 기능 기반의 설명 예시이며 고객 실적이 아닙니다.

2026-09-22 데이터 흐름 모션 영상 추가
- media 폴더의 12초 WebM 영상과 포스터를 포함합니다.
- 첫 화면 진입 시 자동 재생, 반복, 무음이며 영상 컨트롤로 일시정지할 수 있습니다.
- 동작 줄이기 설정 사용 시 자동 재생하지 않습니다.

2026-09-22 모션 방식 변경
- Confluent와 유사한 인라인 흐름도와 데이터 입자 애니메이션으로 변경했습니다.
- 영상 플레이어 대신 SVG 기반 모션을 사용하며, 모션 정지 및 동작 줄이기를 지원합니다.
- 이전 WebM 영상은 media 폴더에 보관되어 있습니다.
