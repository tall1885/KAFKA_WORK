OPASNET Splunk · Confluent 노트북용 페이지
==========================================

실행 방법
1. ZIP 파일의 압축을 풉니다.
2. 압축 해제된 폴더 안의 index.html을 더블클릭합니다.
3. Chrome, Edge, Safari 등 웹 브라우저에서 페이지를 확인합니다.

주의 사항
- 서버나 PHP 설치는 필요하지 않습니다.
- index.html만 따로 이동하면 이미지와 디자인이 표시되지 않습니다.
- css 및 images 폴더를 index.html과 함께 보관하세요.
- 외부 공식 자료와 문의 버튼은 인터넷에 연결된 경우에만 열립니다.

구성 파일
- index.html: 노트북에서 바로 실행하는 페이지
- css/solution-splunk-confluent.css: 페이지 디자인 및 반응형 스타일
- images/sub/splunk-confluent/: Confluent 아키텍처 및 로고 이미지

페이지 구성
- 기존 오파스넷 사업소개 상단 배경과 솔루션 메뉴 구조를 반영했습니다.
- 솔루션 메뉴의 "데이터분석" 다음에 "데이터사업"이 표시됩니다.
- 데이터사업의 기본 선택은 Confluent입니다.
- Confluent/Splunk 탭을 누르면 같은 페이지에서 제품 내용이 전환됩니다.
